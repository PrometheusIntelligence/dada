# 3D lessons (append at the end of every 3D run)

Format: id, what happened, the rule.

**D1 (Last Frequency run 3).** A flat cutaway of a tower read as a picture with nothing to do; the owner asked for first person. A software 3D view of round rooms was built in HolyC in one run. *Rule:* if the owner says "inside", build a space you stand in, not a diagram.
**D2.** Targets found by projecting the drawn boxes matched the picture exactly; a hand-made hit list would have drifted. *Rule:* one geometry list, drawn and projected.
**D3.** The floor was invisible: at 1.6 m eye height a floor object nearer than 2.6 m is below the view. Hatches became ladders with rails. *Rule:* check what is in the frame from the place the player stands, not from above.
**D4.** The first palette gave wall, floor, door and shade of every wooden prop one brown; new props melted into the wall. *Rule:* separate by hue first (warm brick against violet shade, wood against brick).
**D5.** Shadows drawn in the outline colour were invisible. *Rule:* cast shadows get their own tone or sit on a surface that contrasts with it.
**D6.** A dithered light edge and a halftone glow broke the cel style. *Rule:* light is a flat shape with a hard edge.
**D7.** "Too few edges" (owner, run 6): the same scenes at 734 polygons and lines per view looked sparse; adding pilasters, ring beam, cornice, mouldings, blind arches, bevels, furniture structure took it to 1,432 at 34 ms per view under software emulation. *Rule:* measure edges; set a floor; raise it each pass; watch the time.
**D8.** A test returned early because focus was already on the target from a stale layout. *Rule:* tick after placing the camera before any focus loop.
**D9.** Big flat rugs drawn in distance order covered furniture. *Rule:* two passes, flats first.
**D10.** A hanging lantern at the centre of a room filled the screen when the camera passed under it. *Rule:* keep ceiling objects off the walking paths or give them a clearance radius.
**D11 (Last Frequency run 7).** Owner: "way too polygonal, needs more depth". Cause: a 16-sided drum, box furniture, an eight-sided lens. *Rule:* build curves from many narrow quads (48 for a room's wall), round objects as smooth columns (16 facets, three flat tones by the angle to the lamp, hard terminators, ink only on the silhouette and on each terminator, no seams inside a tone), and keep decor on a coarse lattice so cost stays low.
**D12.** Depth in a flat cel renderer comes from bands, not gradients: far wall facets and far objects take the next shade tone; contact shadows (a dark band under a ring beam, a floor edge); overlapping layers (pilasters in front of walls, props in front of pilasters); a lit lens facing the viewer against a dark room.
**D13.** A loop variable reused inside a helper block silently turned a two-pass draw loop into an infinite one and hung the emulator for ten minutes. *Rule:* in C-like languages without block scope, give inner blocks their own variable; time-box every test run and kill it.
**D14.** Stone variation: alternate every other block in a second tone and add a dark bevel under each course; it reads as masonry at 640 by 472 without any texture.
**D15 (Last Frequency run 8).** Owner: "needs more logical passages, windows look weird". Windows were boxes with a dark rectangle in front of the wall, set so high they met the ring beam; stairs ended at the ceiling with no hole. *Rule:* openings are recesses with reveals and a round head, below the beam; every flight arrives at a hole in the ceiling and a hole in the floor above, with a rim; alternate flight directions.
**D16.** A space lint found five real faults in one run (a bed poking 13 cm through the wall, a strip 24 cm through it, a crate inside a bookcase, a table inside a bed, a clock in the beam) that no one had seen in stills. *Rule:* write the lint before the next art pass and run it every time.
**D17.** A union bounding box over a flight of treads swallowed the targets behind it (the filing cabinets could not be clicked because the staircase's box covered them). *Rule:* spread-out objects get one target per part.
**D18.** A bed along a curved wall pokes through it at the corners; turn it radial, head to the wall.
**D19 (Last Frequency run 9).** Owner: "don't see bookcases and globe". They existed, but small, and no stills or first views faced them. *Rule:* every hero prop gets (a) real size and structure (a bookcase has shelves, a ladder and rows of books), (b) a staged still, (c) an arrival view that faces it. If a critic cannot see it in the stills, it does not exist.
**D20.** A coloured box used as a "decal" (vines) read as a solid slab beside a window. *Rule:* flat dressing is a decal (details only, no box); give boxes only to things with thickness.
**D21.** A sphere from five stacked discs looks like a vase. Use nine or more slices with a sqrt profile, and add one or two thin rings, which read as "globe" at once.
**D22.** Concept art windows are tall, multi-pane and arched: stone arch ring, mullions, tracery, a night scene with a tall ship and a moon. Copy the *structure* (many panes, a ring of stone), not only the opening.
**D23 (Last Frequency run 10).** A fixed 100-byte message buffer meets 120-character flavor lines: a silent overflow corrupted neighbouring globals, and the test run then **hung for minutes after the last test** (the process never reached its final log line). It took five bisecting runs to find. *Rule:* size every text buffer for the longest string you will ever write and wrap long text across lines; when a suite hangs after its last test, suspect memory corruption by the newest strings first; log progress lines to the host so a hang can be placed.
**D24.** Texture in a flat 16-colour renderer is marks, not noise: spines with a shade edge, two gold bands, a label and an ink edge; grain as a few long lines on wood and short dashes on planks; stone with course lines, a bevel, a crack every third block and alternate blocks in a second tone; rug fringe as alternating short quads. Count them in the edge budget (1,567 to 1,745 per view).
**D25.** Interaction is part of the space: books that can be read, dials that can be set, shutters that can be closed, each chained to the others by information in a book. Give every named thing one line of flavor and test that no target is silent (83 things on five floors, 0 silent).
