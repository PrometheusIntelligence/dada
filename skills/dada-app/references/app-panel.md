# The panel for an app

`python3 skills/dada/scripts/pick_panel.py --mode adaptive --run-type polish --project <name> --data-graphic` seats
Cairo, Krug, Debord and Tufte. An Adaptive run also needs an Inclusion seat (Mace). Brief every seat from its file in
`skills/dada/seats/` and add only the app duties below. Launch at most three at a time; each files
`panel-R<n>/<seat>.md` as its last action; collect from the directory.

| Seat | App duty (added to its seat file) | What it found in the OperatorOS run |
|---|---|---|
| Critic: Evidence (Cairo) | run the probe and the tests yourself; audit every limit, default and number in the docs against file:line; verify the docs' printed positions against the probe | stale and unmeasured numbers in the docs in every round |
| Critic: Usability (Krug) | five-second test on the phone and desktop first screens from screenshots; trace one named mark end to end; judge whether each fix added confusion | the control stack above the map; icon-only nav; a legend showing 2 of 6 entries |
| Critic: Provocateur (Debord) | claims check on docs, labels, legend, tooltip and footer; read the live DOM to reconcile printed counts with drawn marks | references counted as observations; "tappable" oversold; a pill without its noun |
| Critic: Evidence (Tufte) | measure marks against the data (radius vs count, arcs vs members, draw order, legend vs drawn, non-data ink) in the live DOM | bubble lie factor; mixed colour; halos and a pulse |
| Critic: Inclusion (Mace) | tab count to the first control and the map; focus ring on every mark kind with screenshots; accessible names of every visible control; forced-colors and reduced-motion CSS | no skip link; no focus ring on war, mesh and fleet marks |
| Phone-interaction seat (add; no seat file yet) | run a touch script at 390x844: tap each kind of mark, a bubble, the Filters button, scroll with a finger across the map; report mis-taps and occlusion | not seated in the OperatorOS run; named there as the panel's gap |

A seat's verdict is a file. A required seat with no file is NOT REPORTED, never reconstructed.
