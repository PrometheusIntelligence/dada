# GDADA set pieces (rooms built to be remembered)

The person's words (2026-11-09): "the detailed, dynamic is what we want for a lot of awesome set pieces." Rooms graded B+ and A- (the island, the
dense libraries) have a focal thing, density and a wrong detail; the C rooms were symmetrical and empty. A set piece adds a **dynamic**.

## The six parts
1. **A focal thing** seen on entering. 2. **Density** (gdada L11): walls and aisles full, nothing a bare floor. 3. **A dynamic**: the room changes with the hour,
with the notebook (what you have asked), with what you carry, or with how often you came. 4. **One question** it raises and, where possible, an older question it answers.
5. **A person** who belongs to it, with a complaint and a routine. 6. **One wrong detail** on an ordinary thing (sprite L35).

## Process
Pick the dynamic first (it decides the data a map needs: variants by hour, by flag, by question count), then the focal thing, then fill. Write the set piece
as a short card (the six parts) in `design/gdada-themes.md` before drawing. Check: lint, reachability at every variant, tile plan, scale, art guard.
The brainstorm of 25 set pieces and the order to build them is in the game's `design/gdada-themes.md`.
